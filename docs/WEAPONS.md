# Firearm equipment

Equipment uses item-entry assignments in `assets/gear/weapon-item-map.tsv`. Each row carries an item ID, gun code, exact MW2 script name, weapon category, custom icon, complete authored name and original display-row ID. The client copies the original display row into an item-specific runtime entry, retaining owned retail models while replacing its icon. Shared Warcraft display-model IDs no longer determine the equipped gun or its art. Both clients must run: equipping a firearm requests that exact native weapon from MW2, whose live model and animations are rendered in Benilla.

The current catalogue covers 43 verified native firearms, including all multiplayer assault rifles, SMGs, LMGs, sniper rifles, shotguns, handguns, machine pistols and launchers, plus the native gold Desert Eagle. Each appears on multiple separately named items. The 100 user-supplied names are retained in `weapon-names.tsv`; 93 are assigned at their specified quality. Seven M1911/W1200 names are reserved and unavailable because the current loaded catalogue lacks those exact models. No substitute models are assigned to those names.

Missing artwork uses the closest available user-supplied icon; the model always follows the native script name, not the icon. Existing quality, levels, prices, stats and random enchantments are retained. Complete firearm names do not receive another Warcraft name suffix, but rolled enchantment stats still apply. Fishing poles retain their original role.

The server permits firearms without class or weapon proficiency requirements. Level, race, ownership, reputation and honor checks remain. Firearms use the main-hand equipment slot so native off-hand/dual-wield class restrictions cannot block them. Native item class/subclass IDs remain internal for protocol and combat compatibility; displayed types are firearm categories instead of Sword/Dagger/etc. Armor rules are unchanged.

`scripts/Build-WeaponEquipment.ps1` is a preparation tool, not an automatic database updater. Against an owner's own world database and the native guest catalogue export, it creates an authored mapping and a private `apply-weapons.sql`. It balances gun representation, avoids repeated families in vendor stock, checks native aliases and preserves exact supplied-name rarities. The default excludes unsupported M1911/W1200 models. Back up `item_template`, review generated SQL and restart the patched world server and Benilla after applying it. Do not publish database dumps, native catalogue exports, game assets or local runtime files.
